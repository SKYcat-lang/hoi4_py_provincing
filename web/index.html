왼쪽 위 "맵 폴더 열기" 버튼으로 provinces.bmp가 들어 있는 map/ 폴더(또는 모드 루트)를 선택하세요.

  • 탭 버튼: 프로빈스 편집 / 스테이트 할당 / 자동 분할 모드 전환
  • [자동 분할] 좌클릭: 그 위치의 프로빈스를 선택 → '분할' 버튼으로 평균 px 기준 4가지 알고리즘 혼합 분할
  • [프로빈스 편집] 좌클릭 드래그: 1×1 픽셀 채색 (브러시)
  • [프로빈스 편집] B / G: 브러시 / 페인트통 도구 전환
  • [스테이트 할당] 좌클릭: 그 위치의 스테이트를 현재 선택으로 지정

  • 우클릭 드래그: 화면 팬
  • 휠: 줌 (커서 기준)
  • Ctrl+Z / Ctrl+Y: 실행취소 / 다시실행 (브러시 모드)
