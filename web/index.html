기능

HOI4 Province Painter

왼쪽 위 "맵 폴더 열기" 버튼으로 provinces.bmp가 들어 있는 map/ 폴더(또는 모드 루트)를 선택하세요.

  • 탭 버튼: 프로빈스 편집 / 프로빈스 + / 스테이트 할당 / 전략구역 할당 모드 전환
  • [프로빈스 + → 자동 분할] 좌클릭: 그 위치의 프로빈스를 선택 → '분할' 버튼으로 평균 px 기준 4가지 알고리즘 혼합 분할
  • [프로빈스 + → 프로빈스 이동]: 좌클릭 복수 선택 · 우클릭 해제 · Shift+좌클릭 드래그로 그룹 이동
  • [프로빈스 편집] 좌클릭 드래그: 1×1 픽셀 채색 (브러시)
  • [프로빈스 편집] B / G: 브러시 / 페인트통 도구 전환
  • [스테이트 할당] 좌클릭: 그 위치의 스테이트를 현재 선택으로 지정
  • [스테이트 할당] Shift+좌클릭: 클릭한 프로빈스를 현재 스테이트에 편입
  • [스테이트/전략구역 할당] 우클릭: 클릭한 프로빈스의 현재 할당 해제
  • 그 외 모드 우클릭 (짧게): 스포이드 (해당 픽셀 정보)
  • 우클릭 드래그: 화면 팬
  • 휠: 줌 (커서 기준)
  • Ctrl+Z / Ctrl+Y: 실행취소 / 다시실행 (브러시 모드)
  • Ctrl+S: 저장 (definition.csv, state, strategic regions 자동 갱신)
  • Delete: 커서 위치 프로빈스를 인접 프로빈스로 흡수(=삭제). 19000개 한도 관리용.
  • [인접 연결] 좌클릭 × 2: 두 프로빈스를 잇는 adjacency를 추가 (해협/운하/임패서블).
  • [지형 편집]: terrain.bmp 팔레트 인덱스를 선택해 브러시/페인트통으로 편집합니다.
  • [ / ]: 높이맵 브러시 크기를 줄이거나 늘립니다.
  • 참조 이미지: PNG/JPG/BMP를 화면에 드래그 드롭하면 입력을 가리지 않는 레이어로 표시됩니다.
  • 흰색 프로빈스 테두리: 오른쪽 레이어 패널에서 실제 provinces.bmp 경계를 켜고 끕니다.
  • 핑크색 스테이트 경계: 스테이트 사이와 해안·미할당 외곽 경계를 화면 고정 두께로 표시합니다.
